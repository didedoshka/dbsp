## Выбранный технический путь

Сочетание авторского артефакта и самостоятельной реализации.

### Запросы
Таблицы

`t1(id BIGINT, x BIGINT, a BIGINT);`

`t2(id BIGINT, x BIGINT, s BIGINT);`

Один из запросов для тестирования
```
SELECT t1.x, COUNT(*) AS match
FROM t1
JOIN t2 ON t1.id = t2.id
WHERE t1.a > 20 AND t2.s > 50
GROUP BY t1.x;
```

Сейчас прототип работает на упрощённом запросе [sql/01.sql](../sql/01.sql): `t1(id1, x)`, `t2(id2, y)`, только `JOIN`. Переход на целевой запрос запланирован к КТ-2. `COUNT` по группам линейна: состояние — счётчик на группу, выход — пары (старая строка, −1), (новая, +1).

## Поддерживаемые сценарии

Сначала загружаются две исходные таблицы с помощью запросов вставок. Затем последовательно применяются обновления. В основном эксперименте исследуются вставки и удаления в обеих таблицах.

## Упрощения

Нет null, нет перекоса ключей, нет распределённого выполнения.

Состояние хранится в памяти, отказы и восстановление не рассматриваются. Feldera работает на одном узле с отключённым хранилищем (`storage: None`).

Время Feldera включает HTTP. Проверка эквивалентности стоит O(размер представления) и не входит в замер.
